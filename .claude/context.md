This is LiquidGov.US, a custom civic platform for liquid democracy, maps, live rooms, community features, and related tools. The backend is a modular C++17 HTTP server built with CMake, using a custom file-based store. The frontend is vanilla JS/CSS/HTML assets. Deployment uses shell scripts for feature slices. AI context is supplemented by Persistence/ notes and the CLAUDE.md / .claude/ setup.
