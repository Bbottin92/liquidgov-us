# Share card v4: the exact line, and losing Genesis — deployed

Brandon, directly, three corrections to v3 in one pass:

1. The card should say **"This is YOUR government!"** (the hero's own
   exclamation point, not v3's softened period) and **"REPRESENT YOURSELF"**
   (his own words, as an imperative, not v3's "You represent yourself").
2. "If you can think of anything to make it more inviting go ahead and add
   that" — an open invitation to improve the design, not just swap text.
3. "It shouldn't say genesis either" — the share preview's own `<title>`
   (and therefore `og:title`/`twitter:title`) read "Genesis — LiquidGov.US".
   That's the same word the whole rest of this rebrand has been removing.

## What changed

* **New card, `assets/og-image-v4.jpg`** (1200×630), generated by
  `liquidgov-platform/tools/make_og_card.ps1` (Windows PowerShell +
  `System.Drawing` — this dev environment has no Pillow, no ImageMagick, no
  pip, no sudo; `.NET`'s own image API is the one thing guaranteed present,
  so that's what the generator uses). Re-run the script and commit the new
  JPG to change the card again — never hand-patch the file's bytes, same
  rule `scatter_author.js` uses for `commons/js/world.js`'s SCATTER table.
  Warm gradient instead of v3's flat aged-paper gray, a thin gold
  certificate-style double border, the headline, "REPRESENT YOURSELF" in
  gold letter-spaced caps under a small accent rule, and one new line
  ("Organize. Collaborate. Build what comes next.") that v3 didn't have —
  the actual answer to "make it more inviting": give a stranger a reason to
  click, not just a slogan to read.
* `og:description`/`twitter:description` (`page_wrap`, `http_server.cpp`)
  and `commons/index.html`'s four matching tags: "This is YOUR government!
  Represent yourself — a voluntary association, not a replacement for the
  one you already live under." — the exclamation point and the imperative
  now match the image and the real landing hero exactly.
* The logged-out `/` route's title changed from `wrap("Genesis", ...)` to
  `wrap("Home", ...)` — matching the signed-in dashboard's own title for the
  same page concept. That's what `<title>`, `og:title`, and
  `twitter:title` read from; this is the only place on the whole site that
  still passed "Genesis" into a page title.
* v3 stays served at its old path (same reason v2 still answers under v1's
  retirement) so a crawler that already cached that URL doesn't 404.
